NexuTec - Proyecto Integral de Infraestructura IT

Proyecto académico orientado a la simulación de una empresa proveedora de servicios tecnológicos.

Durante el proyecto se diseñó e implementó una infraestructura informática completa basada en tecnologías Linux y Windows Server para dar servicio a una empresa cliente simulada.

Áreas trabajadas
- Administración de servidores Linux
- Administración de Windows Server
- Active Directory
- Integración LDAP y Samba
- Gestión de dominios
- Compartición de recursos
- Configuración de permisos
- Autenticación de usuarios
- Firewall e iptables
- Copias de seguridad
- Acceso remoto
- Soporte técnico
- Servicios web
- Servidor LAMP
- WordPress
- Hosting de páginas web
- Administración mediante Webmin

Simulación empresarial
Se realizó una simulación de prestación de servicios IT a una empresa cliente, incluyendo:
- Active Directory
- Recursos compartidos
- Firewall
- Acceso remoto
- Copias de seguridad
- Servicios web
- Administración de usuarios

Tecnologías utilizadas
Linux · Windows Server · Active Directory · LDAP · Samba · WordPress · LAMP · Webmin · Firewall · iptables · Networking

Objetivos del proyecto
- Diseñar una infraestructura empresarial funcional.
- Administrar sistemas Linux y Windows.
- Implementar servicios de red.
- Mejorar la seguridad de los sistemas.
- Simular la prestación de servicios tecnológicos a clientes.
